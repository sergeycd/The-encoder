# Obfuscator Decorator

Декоратор для безопасного вывода конфиденциальных данных пользователей при разработке и отладке.

## Описание

При отладке социальной сети часто возникает необходимость выводить на экран тестовые данные пользователей. Для предотвращения случайной утечки конфиденциальной информации декоратор `@obfuscator` преобразует данные в безопасный формат:

- **Логины** (`name`): сохраняются первый и последний символы, остальные заменяются на `*`
- **Пароли** (`password`): полностью заменяются на `*` (с сохранением длины)

## Установка

Просто скопируйте декоратор в свой проект:

```python
from obfuscator import obfuscator
```

## Использование

Примените декоратор к функции, возвращающей словарь с пользовательскими данными:

```python
@obfuscator
def get_user_data():
    return {
        'name': 'Vasya',
        'password': '123456'
    }

print(get_user_data())
# Вывод: {'name': 'V***a', 'password': '******'}
```

## Примеры

### Пример 1
**Входные данные:**
```python
{
    'name': 'Alexander',
    'password': 'qwerty123'
}
```

**Результат:**
```python
{
    'name': 'A*******r',
    'password': '********'
}
```

### Пример 2 (короткие строки)
**Входные данные:**
```python
{
    'name': 'Ai',
    'password': 'x'
}
```

**Результат:**
```python
{
    'name': 'Ai',
    'password': '*'
}
```

## Особенности

- Работает только с ключами `name` и `password`
- Сохраняет исходную длину строк
- Не изменяет другие ключи словаря (если они есть)
- Корректно обрабатывает:
  - Пустые строки
  - Строки из 1-2 символов
  - Специальные символы и Unicode

## Требования

- Python 3.6+
